# 我做了一个上班鼓励器

周末窝在电脑前，突然想起来那个很火的「今日已赚」摸鱼计时器。

打开一看：今天赚了多少、每秒进账多少、离下班还有多久……明明还在摸鱼，却莫名有种「我在赚钱」的错觉。好笑归好笑，我盯着它看了两分钟，忽然有点手痒——要不我也做一个？

于是就有了这个小东西：**上班鼓励器**。

## 为什么要复刻一个？

不是为了颠覆什么，就是单纯觉得好玩。

上班这件事，本身就有点荒诞：你盯着表，表也盯着你。既然逃不掉，不如把「时薪」这件事摊开算清楚——每过一秒，数字跳一下，心里那点「还在熬」的憋屈，会轻一点点。

我给它起名叫「上班鼓励器」，故意有点土，也故意有点暖。它不催你卷，只是在旁边小声说：嘿，你这会儿其实在赚钱呢。

## 做成抖音那种浮动小窗

界面上我故意做成了**抖音那种浮动毛玻璃小窗**的感觉：圆角、半透明、背后虚化，像贴在屏幕上的一块小贴纸，而不是一整页正经后台。

主界面一眼能看到这些：

- **今日已赚**（大号数字，主角）
- 状态：等待开工 / 开工中 / 周末休息中……
- **距离下班** 倒计时
- **本月已赚**
- **今日进度** 进度条
- 底部时薪、上班时间段

深色、浅色主题都能切。摸鱼的时候开深色，像夜里加班的氛围灯；正经开会切浅色，也不至于太扎眼。

![上班鼓励器主界面](https://upload.maynor1024.live/file/1794152435910_app-main.png)

设置面板里可以填月薪、工作日、上下班时间这些——算出来的时薪会直接挂在小窗底下。调完关掉，小窗继续飘着，不影响你假装在看文档。

![设置面板](https://upload.maynor1024.live/file/1794152425455_settings.png)

## 它到底鼓励了谁？

说实话，鼓励的可能不是「更努力上班」，而是——**承认上班这件事很无聊，同时允许自己用一个小玩笑把它过得轻一点**。

周末打开它，会显示「周末休息中」，今日已赚停在 0，本月已赚还在。那种「今天不用演了」的感觉，意外地治愈。

工作日再打开，数字开始跳，倒计时开始跑。你知道它在算账，你也知道生活不止算账——但偶尔看一眼，还是会笑一下。
